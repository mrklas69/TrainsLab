# Diář — 2026-06-12

Kontext a rozhodnutí. Sezení číslovaná (S1…), DD = Design Decision.

## Sezení S39 — nezávislý audit kódu + proměnný vítr

### Diskuse

První sezení Codexu na projektu. `%BEGIN` odhalil, že lokální `main` byl o dva commity
za remote; po fast-forwardu načteno S38. Uživatel označil dosavadní práci za uzavřenou
a zadal nezávislý `%AUDIT:CODE`, zda předchozí agenti něco nepřehlédli. Po opravách
proběhl živý test. Následně přibyl požadavek na náhodně proměnný vítr, který unáší
kouř a páru; uživatel výsledek ověřil jako „Test OK“.

### Rozhodnutí

- Per-frame události rázů se musí nulovat i ve fail state. Jinak poslední `switchFired`
  před vykolejením zůstane aktivní a audio opakuje clunk každý frame.
- `TrackNetwork` musí odmítat nereciproční `next`/`prev`, neplatnou volbu pokračování
  i překročení guardu. Je to příprava na hráčské řízení výhybek ve fázi 3.
- Náhodná brzdová smyčka plánuje změnu hranic podle skutečného `playbackRate`.
- Vítr je čistě view (`WindParams`), nikoli `PhysicsParams`: ovlivňuje world-space
  částice, ne fyziku vlaku. Síla `0 m/s` je explicitní bezvětří.
- Vite 5 → 8 se nemíchá do auditních oprav: jde o samostatný major upgrade s vlastním
  ověřením. Dvě střední npm advisory se týkají vývojového toolchainu.

### Kód

- `%AUDIT:CODE`: opraveny stale event flagy po vykolejení; doplněna validace topologie
  a výsledku `advance(choose)`; `npm run check` přidán do deploy CI.
- `AudioView.makeRandomizedLoop` přeplánovává timer při změně playback rate; odstraněno
  mrtvé API a terminologie sjednocena na parní píšťalu (`playWhistle`).
- `SteamView`: nový `WindParams` (`strength`, `directionVariability`, `changeInterval`).
  Cílový vodorovný vektor mění náhodně směr i sílu a plynule jej dohání. Pára reaguje
  rychleji než hutnější kouř.
- `ControlPanel`: nová sekce Vítr; rozsahy 0–12 m/s, 0–180°, 2–30 s. Default 4 m/s,
  70°, 8 s.
- Regresní testy pokrývají stale event flagy, reciproční topologii a neplatnou volbu
  hrany. `npm run check`, `npx tsc --noEmit` a `npm run build` zelené. Živý test OK.

### Kudos/Censure

- **Kudos!** Nezávislý audit našel reálnou audio regresi, kterou build ani dosavadní
  scénáře nepokrývaly.
- **Kudos!** Požadavek na bezvětří vedl k přirozenému nulovému bodu stejného parametru,
  ne ke speciálnímu přepínači.
- **Censure!** Regresní scénáře existovaly, ale deploy CI je nespouštělo.
- **Censure!** Projektový Codex overlay odkazoval na neexistující `~/.Codex/AGENTS.md`;
  skutečný globální vstup je `~/AGENTS.md` a makra jsou v `~/.claude/PROMPTS.md`.
