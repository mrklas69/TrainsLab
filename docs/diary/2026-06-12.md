# Diář — 2026-06-12

Kontext a rozhodnutí. Sezení číslovaná (S1…), DD = Design Decision.

## Sezení S39 — nezávislý audit kódu + proměnný vítr

### Diskuse

První sezení Codexu na projektu. `%BEGIN` odhalil, že lokální `main` byl o dva commity
za remote; po fast-forwardu načteno S38. Uživatel označil dosavadní práci za uzavřenou
a zadal nezávislý `%AUDIT:CODE`, zda předchozí agenti něco nepřehlédli. Po opravách
proběhl živý test. Následně přibyl požadavek na náhodně proměnný vítr, který unáší
kouř a páru; uživatel výsledek ověřil jako „Test OK“.

### Rozhodnutí

- Per-frame události rázů se musí nulovat i ve fail state. Jinak poslední `switchFired`
  před vykolejením zůstane aktivní a audio opakuje clunk každý frame.
- `TrackNetwork` musí odmítat nereciproční `next`/`prev`, neplatnou volbu pokračování
  i překročení guardu. Je to příprava na hráčské řízení výhybek ve fázi 3.
- Náhodná brzdová smyčka plánuje změnu hranic podle skutečného `playbackRate`.
- Vítr je čistě view (`WindParams`), nikoli `PhysicsParams`: ovlivňuje world-space
  částice, ne fyziku vlaku. Síla `0 m/s` je explicitní bezvětří.
- Vite 5 → 8 se nemíchá do auditních oprav: jde o samostatný major upgrade s vlastním
  ověřením. Dvě střední npm advisory se týkají vývojového toolchainu.

### Kód

- `%AUDIT:CODE`: opraveny stale event flagy po vykolejení; doplněna validace topologie
  a výsledku `advance(choose)`; `npm run check` přidán do deploy CI.
- `AudioView.makeRandomizedLoop` přeplánovává timer při změně playback rate; odstraněno
  mrtvé API a terminologie sjednocena na parní píšťalu (`playWhistle`).
- `SteamView`: nový `WindParams` (`strength`, `directionVariability`, `changeInterval`).
  Cílový vodorovný vektor mění náhodně směr i sílu a plynule jej dohání. Pára reaguje
  rychleji než hutnější kouř.
- `ControlPanel`: nová sekce Vítr; rozsahy 0–12 m/s, 0–180°, 2–30 s. Default 4 m/s,
  70°, 8 s.
- Regresní testy pokrývají stale event flagy, reciproční topologii a neplatnou volbu
  hrany. `npm run check`, `npx tsc --noEmit` a `npm run build` zelené. Živý test OK.

### Kudos/Censure

- **Kudos!** Nezávislý audit našel reálnou audio regresi, kterou build ani dosavadní
  scénáře nepokrývaly.
- **Kudos!** Požadavek na bezvětří vedl k přirozenému nulovému bodu stejného parametru,
  ne ke speciálnímu přepínači.
- **Censure!** Regresní scénáře existovaly, ale deploy CI je nespouštělo.
- **Censure!** Projektový Codex overlay odkazoval na neexistující `~/.Codex/AGENTS.md`;
  skutečný globální vstup je `~/AGENTS.md` a makra jsou v `~/.claude/PROMPTS.md`.

### Příště

- **`%AUDIT:DOCS` + pruning TODO/IDEAS** — oba cadence prahy jsou po S39 překročené
  (naposledy S26). Provést jako první bod příštího sezení.
- Potom podle volby: výhybky fáze 3, nebo samostatný upgrade Vite 5 → 8.

## Sezení S40 — audit dokumentace, pruning a Vite 8

### Diskuse

`%BEGIN` potvrdil čistý synchronizovaný `main` a povinný první bod:
`%AUDIT:DOCS` + pruning `TODO.md`/`IDEAS.md` (S26 → S40). Audit přečetl všech
19 verzovaných Markdown souborů a porovnal aktivní dokumentaci s `src/`, nástroji
i konfigurací. Po opravách uživatel zvolil druhý samostatný řez: upgrade Vite 5 → 8.

### Rozhodnutí

- `TODO.md` drží pouze otevřené úkoly; hotová práce patří do `DONE.md` a diáře.
- `IDEAS.md` drží pouze nezralé směry a hypotézy; rozpracované výhybky jsou v TODO.
- Historické zápisy diáře se kvůli pozdějším přejmenováním nepřepisují.
- Vite upgrade se omezuje na Vite a lockfile; Three.js ani TypeScript se současně
  neposouvají, aby zůstal blast radius čitelný.
- Požadavek Vite 8 na Node je explicitní projektové metadata:
  `^20.19.0 || >=22.12.0`. Lokální Node 22.21 i CI Node 22 vyhovují.
- Nový warning na přibližně 560kB bundle se v tomto řezu neřeší. Code-splitting je
  samostatná optimalizace, ne podmínka toolchain upgradu.

### Dokumentace

- `%AUDIT:DOCS`: opraven routing globálních maker v `CLAUDE.md`, aktuální
  `r_min≈52 m`, terminologie píšťaly a chronologické pořadí S29–S31 v indexu.
- `TODO.md` prořezán z 75 hotových položek na otevřené výhybky fáze 3–4 a domek
  s napaječkou; po dokončení upgradu z něj zmizel i Vite.
- `IDEAS.md` prořezán od hotových bloků a překonaných stavů (`SmokeView`,
  „zbývá 7 zvuků“); zůstaly jen nezralé směry.
- Cadence ledger `%AUDIT:DOCS` i pruning posunut na S40.

### Kód a ověření

- Vite `5.4.21` → `8.0.16`; lockfile přešel z Rollupu na Rolldown.
- `package.json` a README obsahují minimální podporované verze Node.
- `npm ci`, `npm run check`, `npm run build` a `npm audit` zelené;
  audit hlásí 0 zranitelností.
- Lokální Vite 8 dev server ověřen přes HTTP 200 na `127.0.0.1:5173`.
- Permission konfigurace už používá obecné wildcardy; nebylo co čistit.

### Kudos/Censure

- **Kudos!** Audit odhalil rozpad rolí dokumentů: `TODO` a `IDEAS` znovu
  archivovaly hotovou práci navzdory existenci `DONE.md`.
- **Kudos!** Major upgrade proběhl bez zásahu do aplikačního kódu a odstranil
  obě známé střední advisory.
- **Censure!** Aktivní glosář po asymetrii trati stále používal historické
  `r≈33 m`; číselné parametry je nutné aktualizovat spolu s geometrií.

### Příště

- **Výhybky fáze 3 — první řez:** navrhnout route identity a hráčskou volbu
  pokračování v obou směrech tak, aby jedna souprava projela hlavní trať i odbočku.
  Nezačínat kontakty; nejdřív jednoznačná trasa a route-aware poloha.
